🔐 Seguridad

Seguridad de nivel empresarial

🔑 JWT + bcrypt

Tokens firmados con HS256 (7 días). Contraseñas con bcrypt de 12 rondas — el estándar de la industria.

📱 2FA TOTP

Autenticación de dos factores compatible con Google Authenticator, Authy y Microsoft Authenticator.

👥 5 niveles de roles

Owner → Admin → Manager → Agent → Viewer. Cada endpoint verifica el rol en el servidor, no solo en el cliente.

🚦 Rate Limiting

Máximo 20 intentos de login/15min. 120 req/min general. 15 req/min en IA. Bloqueo automático.

🔍 Audit Log completo

Cada acción sensible registra: usuario, acción, entidad, cambios, IP y timestamp.

🛡️ Helmet.js + CORS

Headers HTTP de seguridad: X-Frame-Options, Content-Security-Policy, HSTS, XSS-Protection.
