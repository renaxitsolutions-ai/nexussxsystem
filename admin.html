ℹ️ Cómo funciona el sistema de alertas
  • El sistema monitorea la base de datos en busca de tareas vencidas (fecha límite pasada, no completada)
  • También detecta tickets con SLA incumplido (tiempo de respuesta superado)
  • Al encontrar alertas, envía un email automático a cada responsable
  • Si SMTP no está configurado, las alertas se registran en la consola del servidor
  • En producción, este proceso puede automatizarse con un cron job cada hora
