🖨 Instrucciones para imprimir

  • Usa papel couché o cartulina 300g para las tarjetas de negocio.
  • Imprime en modo "Tamaño real" (sin escalar) para mantener las proporciones.
  • Para los pines, imprime en papel adhesivo de alta calidad y aplica sobre botones/pines en blanco.
  • Selecciona "Guardar como PDF" en la ventana de impresión para obtener un PDF listo para imprenta.
  • Tamaño de tarjeta estándar: 8.5 cm × 5.5 cm (3.5" × 2.17").
  • Pines recomendados: 32mm para circular grande, 25mm para mediano.
